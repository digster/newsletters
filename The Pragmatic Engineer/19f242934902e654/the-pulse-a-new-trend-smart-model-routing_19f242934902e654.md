Full subscribers received the article below three weeks ago. If you’ve been forwarded this email, you can[ subscribe here](https://substack.com/redirect/7bfcbe3e-6870-4541-88e6-27d2a837e9d9?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o).
Two weeks ago, I covered a [trend of companies trying to reduce spending on AI within their engineering departments](https://substack.com/redirect/40072ea2-d0ac-44fc-bc06-4d1683ff996b?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o). While talking to my sources about this, one head of engineering at a larger company told me that they wished there was an ‘intelligent’ router that picks the right model for the right task.
The reason for such a wish is clear; prices for tokens vary greatly per model, and there can easily be a 10-20x difference between a cheap, average model, and a state-of-the-art one.
I did some digging into whether any solutions like this currently exist because the benefits look obvious, and what I found is listed below. Usual disclaimer: I have no affiliation with these vendors, and have not been paid to mention any of them!
Vendors:
[Factory Router](https://substack.com/redirect/c1416a57-826f-4129-ba79-9dbc1fc6555f?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): automatically selecting the right model per session, claiming 20-25% cost savings.[More details](https://substack.com/redirect/c1416a57-826f-4129-ba79-9dbc1fc6555f?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o).[Not Diamond](https://substack.com/redirect/5d053509-c912-4e8b-ab80-6cc76e2aee68?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): auto-selection of coding models, claiming around 30% cost savings. Used by OpenRouter, under the hood.[More details](https://substack.com/redirect/1393dab2-8e2e-4417-aae9-aa073993f23d?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o).[Prism](https://substack.com/redirect/ce49092a-9955-4afd-8356-f6269b32e399?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)by Augment Code. Choosing the “best” model automatically for coding tasks.[More details](https://substack.com/redirect/ce49092a-9955-4afd-8356-f6269b32e399?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o).[Model Router](https://substack.com/redirect/88c06dc5-6b7c-485f-8192-254d26b49979?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)by Morph. An API to suggest model selection for a prompt, based on a list of models.[More details](https://substack.com/redirect/88c06dc5-6b7c-485f-8192-254d26b49979?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)[Weave router](https://substack.com/redirect/fb66ad88-462a-4d51-90a7-1f79c03d0607?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): a token router that works inside Codex, Claude Code and Cursor. “Hard” requests stay on frontier models, while “easy” ones go to open source ones.[More details](https://substack.com/redirect/fb66ad88-462a-4d51-90a7-1f79c03d0607?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)
AI gateways with routing built in. API gateways are popular ways to use LLMs in workplaces.
[OpenRouter](https://substack.com/redirect/1658ac6c-2e51-410e-b883-4e224dbb3bcc?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): comes with “auto router” functionality where, after analyzing the prompt, the best one is selected. Uses Not Diamond under the hood.[More details](https://substack.com/redirect/c26b61b4-9f72-495d-91e5-8d8472f25964?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)[Kilo Gateway](https://substack.com/redirect/2588a0ed-4ce6-4fc1-b523-a789b2105426?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): route requests the model considered the best price-per-value. Supports using your own model keys, and using the service only as a router.[More details](https://substack.com/redirect/2588a0ed-4ce6-4fc1-b523-a789b2105426?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)[Requestly.ai](https://substack.com/redirect/00d3bce4-d36c-4818-b024-d19e047bad1a?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): automatically route requests to the right model based on cost, latency, and availability, and tons of configuration.[More details](https://substack.com/redirect/e4c0e5bb-df6f-4dc0-bdf7-c8247fe4e90a?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)[LiteLLM](https://substack.com/redirect/b75fdcfe-5c52-42bc-b768-f8c5b83fa911?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): define routing rules that automatically select the best model, based on input content with the “auto routing” functionality. The setup is more manual, but you get more control than with many other AI gateways.[More details](https://substack.com/redirect/f3e2582e-6f18-431e-bdf7-60d65f08b828?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)[Envoy AI Gateway](https://substack.com/redirect/b20b8dfc-062a-426e-932a-b112e46055db?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o): an open source gateway that offers some routing configuration, though it feels that the routing engine focuses more on availability, not cost optimization and smart model routing.[More details](https://substack.com/redirect/164fb19e-10bc-4a66-9edb-82fe6bcd6cfa?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o)
Cursor and GitHub Copilot also have an “Auto” model selection that does automatic model selection. For Cursor, it’s a [fixed-price model](https://substack.com/redirect/19c761e3-a34f-45e5-8870-211cfb5d304f?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o) where any savings made are for Cursor: they are not passed on to customers, but the model is cheaper than most others. For Copilot, the [Auto mode](https://substack.com/redirect/3274b14d-372f-4fc0-b284-06a763d1e50c?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o) results in intelligent model selection – but I’ve not heard much positive feedback about this mode from the few devs I asked about it. For Pro plans, Copilot supports pretty old models: GPT-5.5 and Opus 4.8 are not available. These are, however, available on the Pro+ and above plans.
Demand seems to be extremely high for intelligent routing. I asked [Matan Grinberg](https://substack.com/redirect/5d9c0ff4-e708-4449-bbd9-e1998f9741fe?j=eyJ1IjoiOG81NG4ifQ.6oeetudtJEh-zO1onUJvtadWEdbodFIw0h4xbugrh1o), cofounder and CEO at Factory AI, who told me:
“Demand has been off the charts, especially from the enterprise [from large companies.] I’ve met with practically every bank CEO since we launched this offering, because they want a layer to control spend, while still generating high-quality code.
Pretty much everyone in tech is starting to see that open models are often sufficient. We’re seeing open model usage strictly increasing the last six months. My guess is that hosted open models are sufficient in performance for around 60% of coding-related work, in terms of token spend.”
It feels to me that “intelligent routing” will become table stakes, and so we can expect pretty much all AI vendors to build some version of it, and many new vendors to offer this kind of functionality.
