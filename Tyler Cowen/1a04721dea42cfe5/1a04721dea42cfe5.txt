It was very fun talking to @patrickc  ( https://x.com/patrickc )  about New Aesthetics at the @ClunyInstitute  ( https://x.com/ClunyInstitute ) 's conference last month.

We talked about:

> —The origin story of the New Aesthetics grants — and why he and Tyler Cowen disagree on almost everything aesthetic (1:00 ( https://x.com/lukeburgis/status/2093018950334394750?t=60 ) )
>
>  —Why culture is "stuck": a 1926 Bauhaus building could pass for last year's (2:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=150 ) )
>
> —Modernism's explicit, stated mission to tear down beauty — "they weren't hiding it" (3:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=210 ) ) —Solzhenitsyn: you can fake goodness and truth, but beauty "bears within it its own verification" (6:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=390 ) )
>
> —Is beauty objective? Why everyone visits Toledo, Spain and no one visits Toledo, Ohio (7:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=450 ) )
>
>  —Detroit was rich for ~25 years and built the DIA. Silicon Valley's been rich for 50. "We could do the Silicon Valley art tour in a coffee break" (14:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=870 ) )
>
> —Was Y Combinator secretly modeled on the art atelier? (18:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=1110 ) )
>
> —The highest-leverage point for aesthetic renewal used to be churches. What is it now? (27:00 ( https://x.com/lukeburgis/status/2093018950334394750?t=1620 ) )
>
> —The sacred as an "endangered species"
>
> — and Patrick's alternative theory of WTF happened in 1971: we lost the sacred, so we can't have nice things (28:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=1710 ) )
>
>  —I asked him about Vatican II and technological stagnation. He (wisely?) passed. I didn't. (34:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=2070 ) )
>
> —"Can anyone name a work of art made with AI?" Silence. (37:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=2250 ) )
>
> —Why Germany is preeminent in music, literature, and philosophy — and its food is so bad. (A demand-side problem.) (41:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=2490 ) )
>
>  —"Biology is so ugly, man." Physics is beautiful; biology is a tower of hacks (43:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=2610 ) )
>
> —The "anti-beauty conspiracy" of the last century — and the massive latent demand waiting to be uncorked (52:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=3150 ) )
>
> —Patrick reacts live to beeswax art (56:30 ( https://x.com/lukeburgis/status/2093018950334394750?t=3390 ) )
