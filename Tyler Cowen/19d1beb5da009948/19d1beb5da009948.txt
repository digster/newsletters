Yes I will be doing a Conversation with him.  From Wikipedia ( https://en.wikipedia.org/wiki/David_Baszucki ) :

> David Brent Baszucki (/bəˈzuːki/ ( https://en.wikipedia.org/wiki/Help:IPA/English )  buh-ZOO-ki ( https://en.wikipedia.org/wiki/Help:Pronunciation_respelling_key ) ; born January 20, 1963) is a Canadian-born American entrepreneur, engineer, and software developer ( https://en.wikipedia.org/wiki/Software_developer ) . He is best known as the co-founder and CEO of Roblox Corporation ( https://en.wikipedia.org/wiki/Roblox_Corporation ) . He co-founded and was the CEO of Knowledge Revolution, which was acquired by MSC Software ( https://en.wikipedia.org/wiki/MSC_Software )  in December 1998.

On Roblox ( https://en.wikipedia.org/wiki/Roblox ) :

> Roblox (/ˈroʊ.blɒks/ ( https://en.wikipedia.org/wiki/Help:IPA/English )  ⓘ ( https://en.wikipedia.org/wiki/File:LL-Q1860_(eng)-Flame,_not_lame-Roblox.wav ) , ROH-bloks ( https://en.wikipedia.org/wiki/Help:Pronunciation_respelling_key ) ) is an online game ( https://en.wikipedia.org/wiki/Online_game )  platform ( https://en.wikipedia.org/wiki/Computing_platform )  and game creation system ( https://en.wikipedia.org/wiki/Game_creation_system )  developed by Roblox Corporation ( https://en.wikipedia.org/wiki/Roblox_Corporation )  that allows users to program ( https://en.wikipedia.org/wiki/Computer_programming )  and play games created by themselves or other users. It was created by David Baszucki ( https://en.wikipedia.org/wiki/David_Baszucki )  and Erik Cassel in 2004, and released to the public in 2006. As of February 2025, the platform has reported an average of 85.3 million daily active users. According to the company, their monthly player base includes half of all American children under the age of 16.
