When I started The Palindrome, my goal was to bridge the gap between abstract mathematics and practical machine learning.

You’ll be able to join the workshop here: https://open.substack.com/live-stream/127837 [ https://open.substack.com/live-stream/127837 ]
Here is the exact roadmap we’ll follow:
Linear algebra for machine learning.
We start with the language of data itself: vectors and matrices. You’ll see how features, datasets, and model parameters are represented mathematically, and why linear algebra is the foundation of nearly every modern machine learning system.
From theory to NumPy.
We move from theory to custom Python implementations, and finally to NumPy-based versions, learning how vectors and matrices are represented in computations.
Dot products, matrix operations, and vectorization.
These are the building blocks that make machine learning models fast and expressive. We use them to turn a basic linear regression model into a properly vectorized implementation.
Calculus for optimization.
Once the model is defined, the next question is: how do we train it? This part introduces derivatives, rates of change, and the intuition behind optimization.
Gradient descent, explained clearly.
Learn why and how gradient descent works, and how it is used to train machine learning models..
Multivariable calculus and partial derivatives.
Finally, we extend the ideas beyond single-variable calculus, showing how optimization works in practice, when a model has multiple parameters. This is where machine learning gets truly interesting.
(If the time allows, we’ll get into the basics of probability theory as well. )
