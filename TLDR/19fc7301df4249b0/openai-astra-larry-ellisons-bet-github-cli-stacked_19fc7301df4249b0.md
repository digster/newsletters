Montana's plan to become an experimental medical hub just pushed forward (14 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.technologyreview.com%2F2026%2F07%2F30%2F1140942%2Fmontana-experimental-medical-hub-pushed-forward-right-to-try%2F%3Futm_source=tldrnewsletter/1/0100019fc7301ba9-f282b022-936b-461b-b418-10a0aff57fcb-000000/3FfiUM23EajQsj6eh-eUpmI-N0rBLAnMNJwXShHeQvA=452)
Any biotech company with an experimental drug in Montana now has a clear path to selling it to consumers. Companies can now pay $12,500 to apply to a newly established board for approval, as long as the drugs have been through preliminary testing. The drugs will be sold via experimental treatment clinics, the first of which is likely to be open by the end of the year. Patients must provide fully informed consent, and each application must be reviewed by a board that includes a Montana-certified doctor, expert scientists, and an ethicist.

gh stack (GitHub Repo)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Fgithub%2Fgh-stack%3Futm_source=tldrnewsletter/1/0100019fc7301ba9-f282b022-936b-461b-b418-10a0aff57fcb-000000/62_e1_v4g_ZLKV01EAo72mFdu1ldKKWkrMjoU4OHvT4=452)
GitHub Stacked PRs break large changes into a chain of small, reviewable pull requests that build on each other. gh stack is a GitHub CLI extension for managing stacked branches and pull requests. It automates creating branches, keeping them rebased, setting correct PR base branches, and navigating between layers. gh stack offers AI agent integration.
