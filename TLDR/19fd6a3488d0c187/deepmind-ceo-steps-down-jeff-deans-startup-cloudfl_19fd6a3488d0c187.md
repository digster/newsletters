Jeff Dean, Sanjay Ghemawat, Quoc Le, and Oriol Vinyals have left Google to start a company called Discovery Loop. The team aims to build AI that can improve itself with little or no help from humans. Google plans to collaborate with the new startup and has agreed to provide the computing power it needs to build its AI technologies for at least the next year. Discovery Loop will operate as a public benefit corporation.

Cloudflare OS (GitHub Repo)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Fcloudflare%2Fcloudflare-os%3Futm_source=tldrnewsletter/1/0100019fd6a346af-222d083d-40cc-4f59-835d-1ded0c0fdcf7-000000/jdAx7PQBxMjD7d5QlwR2GRvgzBbSucGyU6oUVYlFpcc=452)
Cloudflare OS is an operating system for AI productivity. It features an agent chat UI where users can ask agents to do tasks, sandboxed application development, and a security framework that applies guardrails to both agents and apps. Developed to be used internally at Cloudflare, Cloudflare OS is now open source so others can copy it and customize it for their own companies. The basic user experience of Cloudflare OS is something like an online office suite, but each file is potentially its own custom application written by AI to serve exactly your needs.

What are code reviews even for? (11 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fnewsletter.getdx.com%2Fp%2Fwhat-are-code-reviews-even-for%3Futm_source=tldrnewsletter/1/0100019fd6a346af-222d083d-40cc-4f59-835d-1ded0c0fdcf7-000000/IbVfJmnaErkOEEAesEmPmoF4Q61tS5v1txkN2zU7Y3c=452)
Code review is how teams build a shared understanding of a system. Automating the process removes that shared understanding. AI accelerates cognitive and intent debt - debts that don't appear on a dashboard. By the time anyone realizes, months later, recovering that understanding will be far more expensive than preserving it would have been.
