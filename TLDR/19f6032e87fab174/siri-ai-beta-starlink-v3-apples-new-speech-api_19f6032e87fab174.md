Apple's New Speech API vs Whisper: The First Real Benchmark (9 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fget-inscribe.com%2Fblog%2Fapple-speech-api-benchmark.html%3Futm_source=tldrnewsletter/1/0100019f6032e7b4-95a5f385-4b81-4c22-aaab-f638f6c6a926-000000/fz-98XntLhUnMYbDc6IiF08xO5HTFUT-xY7etR4Fnwc=452)

Control the ideas, not the code (7 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fantirez.com%2Fnews%2F169%3Futm_source=tldrnewsletter/1/0100019f6032e7b4-95a5f385-4b81-4c22-aaab-f638f6c6a926-000000/9z8waMoaUzeOLCklIV06S4bMkvK-repMOpEwIECRFLk=452)
Many programmers are not as impactful as they could be because they are looking at the code. Looking at the code is suboptimal and often pointless. The amount of code that LLMs generate makes it impractical to read, understand, and edit every line of code. It's more efficient to just control the ideas - how things work, what is the best design, and how to reach a certain level of performance - and then check the implementation for correctness.

States Prepare Lawsuit to Block Paramount's Merger With Warner Bros. (8 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FwdL2ut/1/0100019f6032e7b4-95a5f385-4b81-4c22-aaab-f638f6c6a926-000000/l70buHgr3RyqsvTFUpSiLnPWpmg9TeNmQFwDeW6BHLE=452)
Several states are preparing to file a lawsuit to block Paramount's acquisition of Warner Bros. Discovery as soon as this week. The lawsuit claims that the $111 billion deal would harm competition in the market for tentpole films. Paramount says it is prepared to address legitimate antitrust issues and that the merger raises no such concerns. The companies plan to close the deal in the third quarter of this year. Paramount will pay Warner Bros. Discovery's shareholders about $650 million in cash for each quarter the deal doesn't close starting in October.
