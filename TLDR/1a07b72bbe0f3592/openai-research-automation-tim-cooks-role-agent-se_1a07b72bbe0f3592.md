The Curiously Playable Universe (41 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcontraptions.venkateshrao.com%2Fp%2Fthe-curiously-playable-universe%3Futm_source=tldrnewsletter/1/010001a07b72b7e1-b48263a4-f214-45b5-9bcc-c285ae9ede5d-000000/UMtXSiEIU8fpivQ1i_E8r9lzg-H-YF-qYrhGJU8PAnM=452)
A domain becomes playable when enough of its complexity can be compressed into a state where there is some reasonably stable repertoire of actions, interactions can be repeated, outcomes provide feedback about better and worse play, and the environment is stationary enough that lessons learned yesterday remain useful tomorrow. None of these conditions need to be perfect, as playability is a matter of degree. Far more of reality than we have previously expected can be turned into a game. Once something can be turned into a game, then it's possible to create a system that can beat it.

The loop closes (5 minute read)
