OpenAI has released GPT-5.4 mini and GPT-5.4 nano. GPT-5.4 mini is live on the API, Codex, and ChatGPT, while the nano model is reserved for API users only. Both models are designed for workflows where response time shapes the product. GPT-5.4 mini is priced at $0.75 per million input tokens and $4.50 per million output tokens, while GPT-5.4 nano lands at $0.20 and $1.25.

Open SWE: An Open-Source Framework for Internal Coding Agents (7 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.langchain.com%2Fopen-swe-an-open-source-framework-for-internal-coding-agents%2F%3Futm_source=tldrnewsletter/1/0100019d007910f7-d1bd6695-1719-49dd-80d0-839028aeedc7-000000/r1gCikcyvrLCUg4K1-EP3ah2n88mXXqlGqpfrqT_3EE=449)
Open SWE is an open source framework that provides the core architectural components for coding agents. It provides isolated cloud sandboxes, curated toolsets, subagent orchestration, and integration with developer workflows. The framework is intended as a customizable foundation rather than a finished product. Every major component is pluggable.
