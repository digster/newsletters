Introducing the Agents API (5 minute read)

OpenAI's Agents API is now in public beta. The API brings the same harness and infrastructure that powers Codex to developers through a simple and flexible API. It allows developers to create useful agents with a powerful harness that manages context, uses tools efficiently, and coordinates subagents. The API provides infrastructure to keep agents running reliably for days, and environments where agents can work with files, run code, and save intermediate results.
Anthropic Says It Blocked Possible Efforts to Build Biological Weapons (6 minute read)

Anthropic claims it has disrupted several plots to use its AI models to conduct research that could have helped develop biological weapons. The company says it still can't determine whether a query serves a legitimate or nefarious purpose, so it erred on the side of caution as the consequences of mistakes could be severe. Anthropic detected use from companies from blocked regions and parties that otherwise tried to obfuscate their purpose.

Router Power (14 minute read)

Centralized router platforms can offer customers better economics than local deployments. Outcomes pricing belongs to the infrastructure layer. The model layer could offer outcomes pricing, but it will have the same problems as the app layer. Router layer pricing is most politically aligned with customers, who just want to sell more compute and don't care which model is used.
