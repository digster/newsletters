Router Power (14 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2F1730XF/1/010001a0900ec1c0-dd965429-6904-4a59-907f-64ac54d8f046-000000/pSOjQYTHHGqNll-EV82sytNH_qoMQYdhnhULrDnA7Q0=452)

Router layer pricing is most politically aligned with customers, who just want to sell more compute and don't care which model is used.
