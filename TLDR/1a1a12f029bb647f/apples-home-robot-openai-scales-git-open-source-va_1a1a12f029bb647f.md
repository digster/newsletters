SpaceX is reportedly looking at buying Boost Mobile or using its cell network (2 minute read)

SpaceX has held talks with EchoStar to potentially acquire Boost Mobile outright or gain access to its cell network, which is leased from AT&T and T-Mobile. Starlink recently confirmed plans to become a major mobile carrier in the US. The deal will need approval from AT&T and T-Mobile, both of which have already turned down SpaceX for access to their cell towers. SpaceX last year acquired $2.6 billion worth of spectrum licenses from EchoStar to improve its Starlink network's 5G connections.

](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Farstechnica.com%2Fspace%2F2026%2F11%2Fchina-releases-timeline-for-lunar-landing-on-the-moon-targeting-before-2030%2F%3Futm_source=tldrnewsletter/1/010001a1a12f01e8-a73f1ad0-e87c-4cf6-87aa-8d7e711590e5-000000/GptvdUwHJcRAo0-jbo0WgIeZGXhZBy6qsQFDoXng5ig=452)

Why Agents Are Soon Only Going to Have 1 Tool (9 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.philschmid.de%2Fcode-mode%3Futm_source=tldrnewsletter/1/010001a1a12f01e8-a73f1ad0-e87c-4cf6-87aa-8d7e711590e5-000000/VveRfYAUEZ4i-oKC6gpj-u5cB_zLLWi0vlWM9o0rE-c=452)
Agents are collapsing their entire tool catalog into one 'exec' tool. This allows models to write short scripts that chain, combine, and await actions inside isolated sandboxes. Models can now reliably combine and chain dependent actions in a single pass. In the previous standard tool-calling model, agents could only perform single actions, but the exec tool allows them to perform multiple actions.

Scaling Git at OpenAI (31 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FsN4IQP/1/010001a1a12f01e8-a73f1ad0-e87c-4cf6-87aa-8d7e711590e5-000000/IwK5GbUec78QyxWRqEEec-VwljNe_e6T73zNWB8JKQ8=452)
OpenAI's monorepo's size and demands increased at a staggering pace over the last year, necessitating a revamp of the AI lab's source control system. Its technical staff built Pando, a new backend for Git repositories optimized for concurrent pushes to many branches and to maximize read throughput. The team implemented the backend without interrupting any engineering work or changing how the team uses Git. Pando cut median push latency in production by nearly 5x, and it now delivers nearly a petabyte of Git data per day.

The value of open source (16 minute read)
](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fhaydenbleasel.com%2Fwriting%2Fopen-source%3Futm_source=tldrnewsletter/1/010001a1a12f01e8-a73f1ad0-e87c-4cf6-87aa-8d7e711590e5-000000/BEDZKPFk1WSBkKjYwg4Q34rQf0dRS4Da9hR6UpcRqgg=452)
People open source projects for various reasons. Some do it to build a company or product, others do it performatively, and some ship code just for the love of the game. Open source was never free to copy, and the code was never the moat. AI can remake a product, but it can't provide the rest of the value a company generates. The technology is helping maintainers ship and fix problems faster.
